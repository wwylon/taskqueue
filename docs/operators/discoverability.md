# Public discoverability (tqdaemon)

Checklist below is self-contained; the optional sibling `devkit` repo carries only shared house rules.

This product’s marketing surface is top-level [`site/`](../../site/) (GitHub Pages).
Do **not** enable Pages from the `docs/` help tree.

After a public export:

1. Topics / description via `gh` (already set on the public repo when polishing).
2. Homepage → `https://wwylon.github.io/tqdaemon/` only after Pages `/site` is live.
3. Social preview: maintainer uploads `docs/assets/social.jpg` in GitHub Settings.
4. Search Console on the Pages URL (see [`site/README.md`](../../site/README.md)).

Sibling products (upscale, devkit, …): apply the house checklist in their own
sessions or via inbox — not as a silent bulk edit from a tqdaemon change.
